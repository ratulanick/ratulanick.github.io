# ratulanick.github.io

Personal academic and research website for Ratul Anick Paul, Mechanical Engineer and applied researcher in industrial IoT, predictive maintenance, and HVAC/energy systems.

Live at: https://ratulanick.github.io/

## Stack

Plain HTML5, CSS3 and vanilla JavaScript, no build step and no frameworks. Fonts are loaded from Google Fonts (Source Serif 4, Inter, IBM Plex Mono).

## Structure

```
index.html            Single-page site (all sections)
css/variables.css      Design tokens (light/dark)
css/style.css          All styles
js/main.js              Nav, theme toggle, scroll-spy, reveal-on-scroll
assets/images/          Photo and favicon
assets/documents/       Published papers
robots.txt, sitemap.xml SEO
```

## Local preview

Any static file server works, for example:

```
python3 -m http.server 8000
```

then open http://localhost:8000/.
